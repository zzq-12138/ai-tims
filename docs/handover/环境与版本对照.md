# 环境与版本对照（交接用）

> 用途：本地 VM 与公司交付集群是**两套不同代际**的 Kubernetes。所有交付物（manifests、镜像、脚本）必须按**低版本（公司 1.24.17）**写，本地 k3s 只当"跑得通"的验证环境。
> 数据来源：VM 实测（2026-11-04）；公司集群参数为用户提供，细节**需在控制台/集群侧确认**。

## 二、硬约束（写在最前面）

1. **所有 K8s manifests 必须兼容 v1.24**，禁止使用 1.25+ 才有的 API、字段、注解。
2. **禁止写死本地环境地址**：`localhost:5000`、`192.168.40.10`、`127.0.0.1` 只能出现在本地 overlay / kustomize patch 中；交付基线用公司仓库地址与 `imagePullPolicy: IfNotPresent`。
3. **禁止依赖 Traefik 私有 CRD**（`IngressRoute`/`Middleware`）用于交付——本地 k3s 有 Traefik，公司不一定有；只用**标准 `networking.k8s.io/v1 Ingress`**。
4. **禁止依赖 `k3s` 专属能力**（`k3s crictl`、`/var/lib/rancher`、`local-path` StorageClass 名）写在交付基线里；`local-path` 仅本地验证用，公司侧 StorageClass 名需现场确认。
5. 交付前必须做**版本降级自检**（见第六节），本地跑通 ≠ 公司跑通。

## 三、1.24 踩雷清单（逐条对照检查）

### 3.1 已移除/不存在的 API（写了直接 `no matches for kind`）

| 内容 | 1.24 状态 | 正确写法 |
|---|---|---|
| `autoscaling/v2beta1`、`v2beta2` HPA | 1.22 起弃用 / 1.26 移除，1.24 仍可用但**不要用** | 统一 `autoscaling/v2`（1.23 GA） |
| `PodSecurityPolicy`（PSP） | 1.24 起**已移除**（`policy/v1beta1` 不存在） | 用命名空间标签启用 PSA：`pod-security.kubernetes.io/enforce` |
| `networking.k8s.io/v1beta1` Ingress | 1.22 已移除 | `networking.k8s.io/v1` + 必填 `pathType` |
| `policy/v1beta1` PDB / `batch/v1beta1` CronJob | 1.22/1.25 起移除或迁移 | `policy/v1`、`batch/v1` |
| `discovery.k8s.io/v1beta1` EndpointSlice | 1.21 弃用 | `discovery.k8s.io/v1` |
| `flowcontrol.apiserver.k8s.io/v1beta2` | 1.26 才迁 v1beta3 | **1.24 上避免 APF 相关配置** |

### 3.2 1.25+ 才有的字段（1.24 会报 `unknown field` 或静默忽略）

| 字段 / 能力 | 出现版本 | 1.24 处理 |
|---|---|---|
| Sidecar 容器：`initContainers` 内 `restartPolicy: Always` | 1.28 alpha / 1.29 beta | **禁止**；用普通多容器同 Pod 替代 |
| `spec.schedulingGates`（Pod scheduling gates） | 1.26 alpha | **禁止** |
| `spec.resourceClaims`（动态资源分配 DRA） | 1.26 alpha | **禁止**；用常规 resources requests/limits |
| `spec.hostUsers`（用户命名空间） | 1.25 alpha | **禁止** |
| `topologySpreadConstraints` 的 `matchLabelKeys` / `nodeAffinityPolicy` / `nodeTaintsPolicy` | 1.26~1.27 | **禁止**；只用 `maxSkew/topologyKey/whenUnsatisfiable` |
| Job `podFailurePolicy` | 1.25 alpha / 1.26 beta | **禁止** |
| Job `backoffLimitPerIndex`、`maxFailedIndexes` | 1.28 alpha | **禁止** |
| CronJob `spec.timeZone` | 1.27 stable | **禁止**（用容器内 TZ 或应用侧换算） |
| Service `trafficDistribution` | 1.30 alpha | **禁止** |
| NetworkPolicy `endPort` | 1.25 stable | **禁止** |
| HPA 的 `ContainerResource` 指标、`behavior.scaleDown` 精细项 | 1.27 alpha 起 | **禁止**；用 `autoscaling/v2` 的 CPU/内存 + 基础 `behavior` |
| `kubectl debug` 临时容器相关字段（`ephemeralContainers`） | 1.25 stable | 仅调试用，**不进交付 manifests** |
| Pod `spec.os.name`（Windows） | 1.25 stable 的扩展 | 本项目不需要，**禁止** |

### 3.3 Ingress 与入口差异（最容易翻车）

- **字段**：1.24 的 `Ingress` 要求 `pathType` 显式（`Prefix` 或 `Exact`）；`pathType: ImplementationSpecific` 各实现行为不一致，**统一用 `Prefix`**。
- **注解**：`nginx.ingress.kubernetes.io/*` 只在 ingress-nginx 有效，`traefik.ingress.kubernetes.io/*` 只在 Traefik 有效。**交付基线不写任何厂商注解**，需要重写/超时/限流时按公司实际方案补（需现场确认）。
- **IngressClass**：本地 k3s 默认 `traefik`；公司可能是 `nginx` 或其他。**不写 `ingressClassName` 的硬编码值**，交由集群默认 Class；若必须指定，用 kustomize 变量。
- **Traefik v3 vs 公司方案**：本地 k3s v1.36 自带 Traefik v3（具体版本需现场确认），其标准 Ingress 支持子集与 v2 有差异（如部分切面注解语义变化）；**不要把本地"能通"当成公司"能通"**。
- **HTTPS**：本地自签/空证书；公司证书由运维提供，`secretName` 需现场确认。

### 3.4 运行时差异（containerd 2.3 vs 1.6）

- 镜像格式与 OCI 兼容，基本无碍；但 **1.6.24 不支持的部分新特性**（如某些 snapshotter、镜像加速配置字段）不要依赖。
- 本地排查用 `sudo k3s crictl ps/images`；公司侧可能是 `crictl` 直连或 `nerdctl`，**需现场确认**。
- 私有仓库认证：本地 `registries.yaml`（`/etc/rancher/k3s/registries.yaml`）；公司侧是 `imagePullSecret` + 仓库凭据，**两套机制不要混用**。

## 四、网络与镜像约束

| 约束 | 本地 VM | 公司集群 |
|---|---|---|
| 出网 | 需经 `192.168.40.1:7897`（Clash）；Docker 守护进程的代理需在 `daemon.json` 中显式配置（`systemctl restart docker` 生效） | **无外网**，只能访问公司内网仓库 |
| 拉镜像 | 直连 Docker Hub 慢或 403（daocloud 对 `milvusdb/*` 返回 403） | 只走公司仓库；镜像必须先 `tag` 成公司地址再 push |
| 交付方式 | 可在线构建 + 推送 `localhost:5000` | 走既有离线链路：`build → save → 搬运 → load → tag → push`（见 `docs/ops/镜像离线交付手册.md`） |
| 模型 API | 智谱可直连 | 国内大模型可直连（同样需公司出口放行，**需现场确认**） |
| 集群内服务互访 | Service/ClusterIP + 网关 8080 | 同；跨 namespace 需 NetworkPolicy 放行（**需现场确认**是否有默认拒绝策略） |

**镜像命名对照**：

| 场景 | 地址写法 |
|---|---|
| 本地构建推送 | `localhost:5000/tims/{svc}:{ver}` |
| 公司交付 | `{公司仓库地址}/tims/{svc}:{ver}`（地址需现场确认） |
| 拉取策略 | `imagePullPolicy: IfNotPresent`（版本 tag 不可变，禁用 `latest`） |
