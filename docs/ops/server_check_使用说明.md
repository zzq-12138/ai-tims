# 服务器选型体检 · 使用说明

1. 传脚本：本地终端执行 `scp server_check.sh 用户名@服务器IP:/tmp/`（Windows 用 PowerShell 同样命令）。
2. 登录服务器：`ssh 用户名@服务器IP`。
3. 运行：`bash /tmp/server_check.sh`，不用 root；脚本只读，不装软件、不改配置、不删文件。
4. 缺 docker / kubectl / systemctl 的机器会自动跳过对应项，不会报错退出。
5. 提示输入 sudo 密码时直接回车跳过即可，不影响结论。
6. 把终端里从 `== TIMS 服务器选型体检` 到最后一行的**全部输出**复制发回来。
7. 每台候选机各跑一次、分别发回；脚本会给每台机各自打分（推荐 / 勉强可用 / 不建议）。
8. 输出约 50 行、无颜色无分页，窗口拉大后整段复制即可。
