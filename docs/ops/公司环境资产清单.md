# 公司环境资产清单（ai-tims）

> 用途：答辩现场照着念、交付时逐项核对、清理/恢复时确认边界。
> 口径：以公司 **19.64 集群（kubeadm v1.23.17，7 节点）** `ai-tims` namespace 的实际部署为准；与本地仓库 `deploy/k8s/` 不一致的地方在第六节标出。
> 更新日期：**2026-11-23**。上一版（2026-11-18）还把镜像写成 `1.0.0`、前端写成 `1.0.2` 且称「仓库缺 front.yaml」，均已过期——现在仓库有 `base/apps/front.yaml` 并被 `base/kustomization.yaml` 引用（10.23 / 10.25）。
> 事实来源：`docs/ops/公司环境操作记录.md` 10.1~10.34（2026-11-18~20 实测与回读）、`deploy/k8s/overlays/company/kustomization.yaml`、`deploy/k8s/base/apps/front.yaml`、`images/MANIFEST.*`。

## 一、边界一句话

- **我们的**：`ai-tims` 这一个 namespace 内的全部对象。
- **公共的、不能动的**：MySQL / Nacos / Harbor / vLLM，以及任何不在 `ai-tims` 里的对象。
- **清理时**：只删 `ai-tims`；公共资源一律保留。
