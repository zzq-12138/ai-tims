## 2. 逐图卡片

### 图 5-1　三步链式抽取流程

- 文件：`fig5_1_chain_extract.png`（1772×1400 = 15.00×11.85 cm，187,497 B）
- 图题：**图 5-1　三步链式抽取流程**
- 内容：工单关闭事件 → 第 1 步现象定位 → 第 2 步根因与验证 → 第 3 步措施与条件 → 逐步校验门 → 五元组知识（带证据指针与 trace）；底部虚线框说明与「一次性填满槽位」的区别。
- 用途：方法示意，不含实验数值；强调「单步失败即停、证据不足留空是合法输出」。
- 建议位置：5.1「三步链式抽取」首段。
- 依据：`docs/paper/创新点.md` §X.2；`docs/paper/问题二/链式抽取/链式抽取评测.md` §口径说明。
- 源：`make_ch5_fig_5_1.ps1`（依赖 `ch5_common.ps1`）。

### 图 5-2　链式抽取分步指标与适用条件召回

- 图题：**图 5-2　链式抽取分步指标与适用条件召回**

- 用途：结果图，直接支撑「条件字段是最弱项」的判断。

### 图 5-3　去重与冲突判别流程

- 文件：`fig5_3_relation_flow.png`（1772×1350 = 15.00×11.43 cm，188,372 B）
- 图题：**图 5-3　去重与冲突判别流程**

- 用途：方法示意，说明「余弦不能直接当关系标签」以及条件字段在判定中的作用。
- 建议位置：5.2「去重与冲突判别」方法段。
- 依据：`docs/paper/研究方向/标注手册_v1.md` §5.1；`docs/paper/问题二/关系判别/关系判别评测.md` §方法。
