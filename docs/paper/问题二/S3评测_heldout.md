## 0. 结论（先看这三行）

| 组别 | root_cause 一致率 | measures 条目 F1 | excluded 检出率 | 排除假设误当根因 |
|---|---|---|---|---|
| S1 基座零样本 | 86.5% | 0.944 | 68.8% | 2.5% |
| S2 基座 + 规则提示词 | 95.0% | 0.944 | 100% | 0% |
| **S3 基座 + LoRA** | **99.0%** | **0.990** | **100%** | **0%** |

- **主结论**：同一提示词、同一贪心解码下，S3 相对 S1 的 `root_cause` 一致率 **+12.5 pp**（86.5 → 99.0），
  excluded 检出率 **+31.2 pp**（68.8 → 100），排除假设误当根因从 **2.5% → 0%**。
- **规则能补一半**：S2（提示词规则 + 字段校验，无微调）把 root 拉到 95.0%、excluded 拉到 100%，
  但**措施指标停滞在 0.944**（与 S1 逐条相同 174/200），且在 5 条正常样本上"过度保守"输出空根因；
  S3 再补 +4.0 pp root、+0.046 measures，且无空根因副作用。
- **增益集中在一个失败模式**：20 条"无最终根因"样本上，S1 **20/20 全部编造根因**（"根因未定/暂未定位"或凭措施反推），
  S2/S3 全部正确留空。另外 7 条 S1 错误来自漏抽/误抽排除假设。S3 只剩 2 条错误（同一模板，把观测句当结论）。
- **代价**：S3 单条推理 11.6 s vs S1 5.7 s / S2 5.5 s（同一 4090D，LoRA 未合并权重），200 条总耗时 38.5 min vs 18.9/18.3 min。

| 组别 | 模型 | 提示词 | 后处理 |

### 1.3 解码与推理

- 贪心解码：`do_sample=False`，`max_new_tokens=384`，`add_generation_prompt=True`，bf16，batch=1。
- 每条最多重试 3 次，失败写 `error` 字段；本轮 **S1/S2/S3 各 200 条，`error=0`，重试 0 次**。
- 截断检查：S1/S3 各 200 条输出**全部以 `}` 结尾**；S2 经字段校验后 200/200 可解析 → 全组 JSON 解析失败 0 条，384 足够，无截断。
- 耗时：S1 平均 5.66 s/条（峰值 8.3 s），S2 5.48 s/条（峰值 8.7 s），S3 11.55 s/条（峰值 19.9 s）。
- 显存峰值：S1 14.32 GB / S2 14.36 GB / S3 14.55 GB。

### 1.4 指标口径（可复现，不做黑箱"语义判等"）

| 指标 | 判定方式 |
|---|---|
| JSON 合法率 | 去 ```` ``` ```` 围栏后，从每个 `{` 起 `json.JSONDecoder().raw_decode` 能解出 dict |
| 14 字段齐全率 | 上述 dict 同时含 14 个字段名 |
| root_cause 一致率 | NFKC 归一化 + 小写 + 仅保留中英文/数字后，字符 bigram Dice ≥ 0.55；或一方包含另一方且长度比 ≥ 0.6。同时报"归一化后完全相等"的 exact 率 |
| measures | 条目级**一对一贪心匹配**（Dice ≥ 0.5 记命中），算 P/R/F1；空对空记 None 不参与平均 |
| excluded 抽取 | 同上条目级匹配；"检出"= gold 有排除假设且预测非空；**误抽率** = gold 的某条排除假设与预测 `root_cause` 被判等（Dice ≥ 0.55）的样本占比 |

这 5 条**语义正确、只是丢了括号里的测量值**，属判等口径偏严（见 §7）。

### 5.4 S3 的残余失败（2 条根因 + 2 条措施，共 4 处）

**H0040 / H0170（wechat / normal，同一模板，仅设备号不同）**
- 原文摘要："同批板材厚度实测一致，喷淋流量分布偏差 25%，就是喷淋管部分孔位堵塞导致流量分布不均"。

### 5.5 S1 的措施切分粒度（指标层面的"假失败"）

**H0009（同上）**：S1 的 `更换0402吸嘴` + `用清洗液超声清洗真空通道` 内容完全正确，只因 gold 把并列动作合成一条，条目级 P 被拉低。
因此 §3.2 中 S1 在 wechat 的 0.871 应理解为"**切分口径不一致**"为主，而非内容缺失。S3 与 gold 的切分方式一致，分数高一部分来自**模仿 gold 的条目边界**。

### 5.6 S2：规则把"没有明说结论"判得过严

**H0002（wechat / normal）**
- 原文摘要：贴合后出现 1–3mm 气泡；"胶层厚度实测均匀，辊面压力两端 0.2MPa（中间 0.45MPa），**就是贴合辊压力不均，两端偏低**"；调整两端压力至 0.45MPa、更换老化辊面；连续 200 片无气泡。
- 真值 root：`贴合辊压力不均，两端偏低`
- S1 预测：正确（完整取到"就是…"后的结论）
- S2 预测：**空字符串**，`has_final_root_cause=0` —— 规则 2"不要把观测句当根因"被执行过头，模型把整句（含结论）都当成了观测
- S3 预测：正确 ✓

同类 5 条：H0002 / H0067 / H0101 / H0102 / H0187，全部是 normal 切片被 S2 误清空（且都是"现场核对/就是 X"这一结论句式）。
这是纯规则路线最典型的翻车方式：**压住了幻觉，也压掉了真结论**——S2 在这 5 条上比 S1 更差；
S3 从训练样本里学到了"就是 X"后面就是根因，同一句式只剩 H0040/H0170 两条错误（见 5.4）。

**H0132 / H0198 / H0082 / H0172 / H0192（S2 判等"失败"但语义正确）**
- 例：gold `蚀刻液温度偏低（实测 42℃，设定 50℃）`，S2 输出 `蚀刻液温度偏低`
- 判定为不等，是因为 Dice = 2×7/(7+20) ≈ 0.52 < 0.55，且长度比 0.35 < 0.6。
- 这 5 条应视为**判等口径的假阴性**，S2 的真实 root 正确率约为 97.5%（195/200），高于表中 95.0%。

## 6. S3 相对 S1 / S2 的增量与不足

### 增量（有数字支撑）

1. **"没结论时不要编"**：no_final 20 条 root 一致率 0% → 100%。S2 靠显式规则也能做到，但代价是 normal 上 5 条误清空；S3 同时保住 normal（98.3%），是 S3 相对 S2 的主要优势（+4.0 pp root）。
2. **排除假设抽取**：检出率 68.8% → 100%，条目召回 73% → 100%，logbook 模板 +48.3 pp 最明显。**这一项 S2 已满分，微调没有额外增益。**
3. **排除假设误当根因**：2.5% → 0%（wechat 切片 6.9% → 0%）。S2 同样 0%。
4. **输出稳定性**：S1 出现 `has_final_root_cause` 与 `root_cause` 自相矛盾的样本，S2/S3 无（100% 一致）。
5. **措施条目边界与 gold 对齐**：wechat measures F1 0.871 → 0.985，**S2 无法做到（0.868，与 S1 174/200 逐字相同）**——这是微调独有的增益，也是 S3 相对 S2 的 measures +0.046 全部来源。

**一句话**：规则（S2）能拿到"格式/字段/排除假设/不编造"的大部分收益，**微调（S3）额外买到的是"结论句语义定位 + 措施条目边界"**，这两项恰好是提示词说不清的。

### 不足

1. **句内结论定位仍会错**：H0040/H0170 把观测句当根因；说明 S3 学到的是"模板位置"而非"结论语义"，遇到"就是…"这类标记时可能截断前半句。
2. **no_final 下措施选取**：H0147/H0030 抓错动作段（把"降速跑着/继续检查"当措施），S3 对"已执行动作"与"临时/后续动作"的区分不齐。
3. **成本**：未合并 adapter 时推理 11.6 s/条（S1 5.7 s / S2 5.5 s），约 2 倍；训练另计 23.9 min / 卡。
4. **增益的边界**：S1 在 normal/excluded 上已有 96.7%/95.0%；S2 在 excluded 上已 95.0%。**如果线上文本都带明确结论、且只需字段级结构化，S2 的性价比明显更高；S3 的不可替代性集中在无结论样本与措施粒度上。**

## 7. 局限（写论文时必须带上）

1. **留出集与训练集同源构造**：200 条与 1000 条由同一套生成器按三种模板构造，句式高度同构（"先怀疑 X，换了试了没用，排除 X"）。S3 的 near-ceiling 分数说明它**学会了模板与字段边界**，不能外推为真实工单（自由表述、口语、错别字、跨段指代）上的同等水平。
2. **gold 高度抽取式**：措施/证据/排除假设多为原文子串，条目级 F1 对"照抄能力"奖励过高；真实标注若为改写式，分数会下降。
3. **判等是规则口径，不是独立模型判等**：root_cause 用字符 bigram Dice（阈值 0.55）+ 包含关系，可能对"换一种说法但同义"的预测判错，也可能对"共享大量字面但语义不同"的预测判对。未跑 blind_eval 式的独立模型判等。
4. **measures 指标惩罚切分差异**：S1 的内容正确率被低估（见 5.5）；S3 的优势部分来自与 gold 相同的切分习惯。
5. **S2 只实现了提示词约束 + 字段校验**，未实现路线文档里的槽位/单位/设备名校验与规则后处理全套；且 S2 的规则是**在看到 S1 的失败模式之后写的**，对留出集存在过拟合风险，95.0% 应视为偏乐观的点估计。另外 S2 的 5 条 normal 误清空与 5 条判等假阴性说明：规则路线需要开发集调阈值，不能一次写死。
6. **单次训练、无随机种子方差、无置信区间**：n=200 时 1 条 = 0.5 pp，root 一致率差 12.5 pp 约 25 条，方向明确但未做 McNemar 检验。
7. **未做 S4（更大模型零样本上界）**，也未评估合并 adapter 后的推理加速。
