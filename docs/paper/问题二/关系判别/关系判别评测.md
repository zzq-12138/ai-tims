# 四类关系判别评测（P1）

> 真值：`_gold_relation_draft.jsonl`，由生成器在造对时确定（construction-based gold，弱监督），**不是人工标注**。
> 指标口径：与构造真值的一致性；样本为跨设备模板合成语料，不外推真实工单能力。

## 方法

1. **相似度**：BGE-M3 余弦，作为召回特征。
2. **结构化规则**：解析现象/根因/措施/验证/条件，比较现象与根因是否同一、措施是否重叠。
3. **条件互斥**：同类型条件值不同 → 互斥（判 variant）；条件重叠或缺失 → 允许 conflict。
4. **LLM 复核**：仅当条件状态未知（unknown）或规则落入灰区时交 glm-4-flash 判别；
   条件明确（重叠/一侧缺失/互斥）时以结构化规则为准；LLM 判 conflict 但条件互斥时，
   再由条件规则收口为 variant。

## B. 反构造检验（删除「适用条件」与设备/产线/工艺段上下文行）

### B.0 反构造集是怎么造的（方法说明，供质疑时答辩）

- **来源**：与构造集**同源**，直接取同一份 300 对样本（duplicate 90 / variant 90 / conflict 80 / unrelated 40），不重新生成、不重新标注。
- **剥离对象**：只删除两类行——① 以「适用条件：」开头的行；② 以「设备型号：」「产线：」「工艺段：」开头的上下文行。实现为正则 `^(适用条件|设备型号|产线|工艺段)[：:]` 逐行过滤（`relation_classify.py::strip_artifacts`）。
- **未剥离**：现象、原因、处理/处置、验证四类字段原样保留；因此该集合测的是「条件与上下文信号缺失」这一种退化，不是全字段扰动。
- **规模**：300 对全部重算，数量与真值标签不变。
- **性质与边界**：这是「同源去痕迹」的消融对照，不是独立构造的新数据集；它能回答「构造规律贡献了多少」，不能回答「真实工单上的绝对性能」。更严格的独立重写集（换生成器、换设备）仍列为待补。

> 删除的两类行是构造集里 variant/conflict 的强标签信号（variant 必带适用条件、conflict 必共享上下文）。
> 删除后模型只能靠现象/根因/措施的语义判断，这是检验「规则是否真有用」的对照。

## 结论：哪一组数字能外推

### 1. 结论方向：反构造集上「余弦更稳」，原结论不成立

- 同一份反构造集上三方 macro-F1：**sim 0.8560 > full 0.7189 > rule 0.6600**（Accuracy 0.8433 / 0.7000 / 0.7000）。
- 因此**不能写“规则+条件互斥胜过多相似度”**。该结论只在保留构造痕迹的构造集上成立（rule/full 1.0000 vs sim 0.8923），属于**构造集上界**。
- 为什么反转：
  - rule 的两个高置信判据——「variant 必带适用条件行」「conflict 必共享上下文行」——正是本检验剥离的信号；
  - 剥离后 `sym_same & !cause_same` 全部落入默认分支，rule 把 **90/90** 条 variant 判成 conflict，variant F1 = 0.0000；
  - full 用 LLM 救回 variant（57/90，F1 0.5616），代价是 **56/80** 条 conflict 被改判 variant，conflict F1 从 0.7729（sim）掉到 0.3566；
  - sim 不依赖条件，保持 conflict 全召回（80/80），只在 variant 上漏 46 条，因此 macro 最优。

### 2. 可外推的表述

- **主结果行用反构造集**：sim 0.8560 / full 0.7189 / rule 0.6600；构造集 1.0000 一律标注“构造集上界”，不得单独引用。
- **variant F1 必须成对出现**：1.000（构造集）→ 0.5616（反构造 full）→ 0.0000（反构造 rule）。
- 能站住的结论：**条件字段缺失时，纯余弦是三者中最稳的；条件互斥规则的收益依赖条件字段真实存在且可抽取**。
- 该前提由 P0 链式抽取承接（留出集适用条件 F1 0.536，仍是最弱项），因此 P1 不能单独部署在没有条件字段的知识上；二者是依赖关系，不是替代关系。

### 3. 答辩口径：你的规则在真实数据上还成立吗

> 只在条件字段可用时成立。构造集上 1.0000 是上界，反构造集上 rule 0.6600、full 0.7189，都低于纯余弦 0.8560；
> 说明剥离条件与上下文后，规则的结构信号缺失会带来负收益。真实工单上条件是否可得取决于 P0 抽取（0.536），
> 所以本文主张的是“条件互斥在条件可用时可纠正结构性 variant→conflict 误判”，不是“规则在真实数据上更强”。

### 4. 逐对留痕

- 逐对预测与错判理由见 `relation_pred_orig_{sim,rule,full}.jsonl` / `relation_pred_anti_{sim,rule,full}.jsonl`（每对一行，含 gold/pred/confidence/sim/condition_state/reason）。
- 两组都受模板合成语料限制，不能外推到真实工单；关系集本身仍是 construction-based gold。
- 反构造集是“同源去痕迹”消融，不是独立重写集；更严格的独立构造对照列为待补。

## 局限

1. 关系集由模板定向构造（duplicate 换词、variant 换根因/条件、conflict 选 0.85–0.95 相似带），
   存在构造痕迹；指标只说明方法在该构造集上可分。
2. variant 与 conflict 的相似度分布重叠（见 `_relation_stats.json`），单靠阈值不可分。
3. LLM 判别使用 glm-4-flash，与现网抽取模型同源，不构成独立第三方评审。
