# 盲评 v2 的 κ 复核与脚本修复（2026-11-07）

> 起因：台账 C-16 指出「盲评 v2 的 κ 与 p_e 全是 1.000」，怀疑是计算损坏。
> 结论先行：**p_e 公式与数组对齐都没错，pred 也不是 gold 的副本；真正的缺陷只有一处——单类退化时把未定义的 κ 硬编码成 1.0。**
> 本文**不覆盖**历史输出 `盲评一致性报告_修复后.md`；旧版脚本保留为 `scripts/annotation/compute_kappa_v1.py` 供对照。

## 一、复核方法与证据

| 检查项 | 结果 | 证据 |
|---|---|---|
| 是否「自己比自己」 | **否** | `pred_flat` 与 `gold_flat` 逐条 JSON 完全相同的条数 = **0 / 1000**；若复制，应为 1000 |
| 是否维度/索引错位 | **否** | 两侧按 `ticket_id` 对齐后交集 1000/1000；混淆矩阵对角外有大量计数（见 §三） |
| p_e 公式 | **正确** | `p_e = Σ_i p(A=i)·p(B=i)`，即两侧边际分布的内积，与 Cohen (1960) 一致；旧脚本第 102–104 行实现无误 |
| 分母是否正确 | **正确** | `1 − p_e`；`p_o = Σ diag / n` |
| 唯一缺陷 | **`k = 1.0 if pe == 1`** | 单类时 κ = 0/0 无定义，旧实现返回 1.0，被渲染成「完全一致」 |

复现数据（n=1000）：

- `/tmp/blind_gold_flat.jsonl`：md5 `0cb5bef0ae6feb408f64d661e01436aa`，1000 行
- `/tmp/blind_pred_flat.jsonl`：md5 `5d3594dbc0a1a6a1dd5a7e07a8db394c`，1000 行
- 旧脚本输出：`/tmp/kappa_v1.md`；修复后输出：`/tmp/kappa_fixed.md`

## 五、对论文的影响

**可用结论（可说）**

- L2 盲评**仍然可用**：两个真正二值化的字段 κ 分别为 **0.809**（排除假设判定）与 **1.000**（有无最终根因，p_e 0.820），根因标签 κ **0.828**（n=900）。
- 三层证据链表述改为：「L1 程序自检 → L2 模型盲评（二值判定类 κ 0.809–1.000；根因标签 κ 0.828）→ L3 用户人工抽检复核无异议」。
- 自由文本槽位（现象/措施/验证/条件）**用语义一致率而非 κ**：现象 94.11%、措施 99.40%、条件 13.77%（见 §一/§二）。

**不可说**

- ❌「盲评所有字段 κ = 1.000，完全一致」——其中 4 个字段是单类退化，κ 无定义。
- ❌「条件抽取一致率 100%」——条件一致率 13.77%，κ 无定义不代表一致。
- ❌ 用「κ 1.000」证明标注质量——κ 只能证明**两个判断过程**在给定类别分布下的一致性；本盲评是「模型 vs 构造真值」，不是双人标注，σ 与 κ 都不得写成「标注者间一致性」。

**残余风险**

- `root_cause` 的 κ 只在 900 条非空样本上计算（100 条 no_final 被排除），不能外推为 1000 条整体一致性。
- `has_final_root_cause` κ=1.000 建立在高不平衡（900:100）上，p_e 已 0.820，解释时应同时报 p_o 与 p_e。
