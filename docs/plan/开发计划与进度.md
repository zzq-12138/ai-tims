## 四、风险与关键路径

- **最紧节点：开题 2027-01 上旬**。开题只写到 M3，M0~M3 必须在 2026-12-31 前可演示——目前 M0~M3 已完成，**该节点风险已基本解除**，剩余工作是把演示脚本与截图补齐。
- **关键路径**：M7 数据集 → M7 实验 → 论文实验章节。若 12 月前不能确定数据集口径（多少条、如何标注、对比基线），会挤压论文写作时间。
- **k3s 网络依赖**：系统组件镜像拉取受阻在 VM 上；若寒假前不解决，M8 演示环境会被推迟。两条退路：① 临时挂 Clash 代理（`192.168.40.1:7897`）；② 走现有离线镜像交付链路（build → save → 搬运 → load）。
- **版本落差风险**：公司集群 K8s **v1.24.17**，本机 k3s **v1.36.5**，manifests 必须按 1.24 口径写（详见 `docs/handover/环境与版本对照.md`），否则 M8 交付时需重写。
- **资源风险**：4 vCPU / 15Gi，k3s 控制面 + Milvus + 六服务并存会争核；压测与编译需分时段（DEVLOG 已拍板）。
- **数据风险**：虚拟机磁盘曾出现文件尾字节丢失（Windows 侧写入环节），大改动前须拍快照；DEVLOG 已有记录。
