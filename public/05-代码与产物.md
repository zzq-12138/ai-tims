## 5. 构建与导出方式（备查）

### 5.1 后端

```bash
cd /home/dev/ai-tims/ai-tims-parent
mvn -B -pl ticket-ai,ticket-knowledge -am -DskipTests package

cd /home/dev/ai-tims
docker build \
  --build-arg JAR_FILE=ai-tims-parent/ticket-ai/target/ticket-ai-1.0.0-SNAPSHOT.jar \
  -f deploy/docker/Dockerfile \
  -t harbor.xnunion.com/library/ticket-ai:<tag> .
```

`ticket-knowledge` 同理换 `JAR_FILE` 与 tag。

### 5.2 前端

```bash
cd /home/dev/ai-tims
docker build -f ai-tims-front/Dockerfile -t harbor.xnunion.com/library/ai-tims-front:<tag> ai-tims-front
```

Dockerfile 是多阶段：`node:20-alpine` 内 `npm install`（npmmirror）+ `npm run build`，运行层 `nginx:1.27-alpine`。

### 5.3 导出与自检

```bash
gzip -t <包>
tar -xzOf <包> manifest.json      # 确认 RepoTags 是目标镜像
md5sum -c MANIFEST.md5
```

只导出本次要发的包，不要顺手重打其他服务或中间件。
