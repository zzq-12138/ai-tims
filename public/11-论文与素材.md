## 五、红线（写进论文前必须核对）

1. **0.7691 不能单独引用**：控制台模拟检索的实时观察值，未落库、无日志、不可事后复核；且是旧模型口径。可引的是 `0.7696`（P-080，`蚀刻机 刻过头了…`；旧 embedding 模型下的读数，与当前模型不可比）和 `0.76701`（`回流焊8温区温度偏低 焊点虚焊`，11-19 单点验证）。**0.6589 属噪声版 query（P-080）在当前模型下的读数，已作废：它不能代表干净 query**——干净 query `蚀刻机过蚀刻怎么处理` 现测 VECTOR/HYBRID 均 **0.7737、A 档**，不能把 0.6589 写成「同一 query 的复现」或趋势证据。
2. **知识库条数以 2026-11-23 MySQL 实查 328 条为准**，旧文档里的 322/319/311 一律不再引用。
3. **单条 query 的实测（n=1）只能证明配置生效、方向一致**，不能当统计结论；统计结论用 300 条扫描那一组。
4. **公司环境数据不得外发**：内网与外网不互通，公司侧文件（csv/json/png/tar/镜像包/日志）一律不得外发；需要数据时在公司机聚合，只回传纯文本结果，单次一两千行以内。详见 [03-环境与访问.md](03-环境与访问.md) §8。

### 门控口径三条

1. **2.4% 不是整体错误推送率**：它是正例池内的正例错误率，不能外推为系统整体错误推送率。
2. **不能写「已降到 3% 以下」或「已达标」**：按「混合错误率 ≤3% 且覆盖 ≥30%」口径，本轮没有达标工作点；唯一 ≤3% 的是 T=0.85，但覆盖只剩 26%。0.70 是为救回被误杀的正确回答所做的取舍点（正例覆盖 82.0%、正例错误率 2.4%）。
3. **不能再写「现网阈值 0.75」**：现行门控是 `gateThreshold=0.70` + 软带 `0.07`（A ≥ 0.77，B 为 [0.70, 0.77)）；0.75 是旧「智谱 embedding-3 + 55 条库」基线，在本环境已失效。
